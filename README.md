# Customer Data ETL Pipeline



## Project Overview



End-to-end Data Engineering project that extracts customer, order, order-item and product data from CSV files, transforms and validates the data using Python and Pandas, and loads the processed data into PostgreSQL.



## Tech Stack



\* Python

\* Pandas

\* PostgreSQL

\* SQL

\* Git \& GitHub

```text
&#x20;  ↓

&#x20;  ↓

&#x20;  ↓

SQL Analysis

```



## Dataset



The project contains four main source datasets:



\* `customers.csv` — 300 customers

\* `orders.csv` — 1,000 orders

\* `order\_items.csv` — 2,000 source records

\* `products.csv` — 50 products



After transformation and validation, 1,967 valid order-item records were loaded into PostgreSQL.



## ETL Process



### 1. Extract



Python and Pandas read the CSV files from the raw data directory.



### 2. Transform



The pipeline performs data cleaning and transformation before loading the data into PostgreSQL.



### 3. Validate



The pipeline validates:



\* Record counts

\* Customer references

\* Order references

\* Product references

\* Duplicate orders

\* Invalid quantities

\* Invalid prices



### 4. Load



Validated data is loaded into PostgreSQL tables:



```text

customers

orders

order\_items

products

```

## How to Run



Create and activate a Python virtual environment:



```powershell

python -m venv venv

.\\venv\\Scripts\\Activate.ps1

```



Install dependencies:



```powershell

pip install pandas psycopg2-binary

```



Run the ETL pipeline:



```powershell

python ".\\etl\\etl\_pipeline.py"

```



Run SQL analysis:



```powershell

psql -U postgres -d customer\_etl\_db -f ".\\sql\\analysis.sql"

```
